# 从源码构建

正式源码入口为本仓库。需要 Windows、PowerShell 7、Visual Studio 2022 Build Tools（MSVC、Windows SDK）、Python 3.12，以及带 Frida 17.19.0 和许可证的可分发 Python 运行目录。

```powershell
pwsh -File ./work/native-bd/build.ps1
python ./work/native-bd/test_aura_plans.py
python ./work/native-bd/test_localization.py
$commit = git rev-parse HEAD
python ./tools/build_release.py --runtime-dir '<Python 与 Frida 运行目录>' --commit $commit
```

`build.ps1` 从源码构建覆盖界面和 version.dll 代理加载器。`build_release.py` 只归档明确允许文件，校验每项 SHA-256，写入对应提交及版本，禁止加入存档、个人方案与日志。Git HEAD 必须先提交并确认已推送，再产生外部分发候选。

目录中的 `catalog.py`、`catalog_english.py` 是目录再生成工具，读取本机游戏数据；公开仓库不包含完整原版组件表和游戏 EXE。通常无需再生成已验证的目录。
