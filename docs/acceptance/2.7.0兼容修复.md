## 原因与修改

游戏更新为 2.7.0；原版控制器只接受 2.6.4 EXE 哈希，导致自动加载退出。进一步核对发现，原生函数、全局对象、新局计数和保存调度字段也发生了移动，不能只删除版本条件。

已移除安装和运行中的 EXE 哈希白名单以及组件文件整体哈希门禁。改用 19 个唯一代码锚点解析实际原生入口、全局对象及字段；函数调用必须落在 PE 原生函数表中的入口，运行时检查房间路径、字段、组件 ID 和字典结构。EXE 无关内容变化不阻止加载，接口缺失或歧义会明确报错。

保留 Mod 安装包自身的文件哈希校验：这是文件完整性检查，不是游戏版本限制。
